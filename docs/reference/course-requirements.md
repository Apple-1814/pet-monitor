# 课程设计要求（宠物视频监控系统）

> 来源：`农业物联网综合设计题目26年.ppt`（已转换为 `农业物联网综合设计题目26年.pdf` 备查）
> 题目：**第 4 题 宠物视频监控系统**

## 1. 题目要求

- 设计宠物远程视频监控系统。
- 采用 STM32 系列、S3C2440 或其他 32 位 MCU/SoC。

## 2. 功能要求

| 级别 | 功能 | 当前状态 |
|---|---|---|
| 基础① | 通过 STM32 控制器驱动摄像头 | ✅ 已完成（OV7670 + AL422 FIFO，PID=0x76/VER=0x73） |
| 基础② | 在显示屏上显示摄像头视频 | ✅ 已完成（NT35310 3.5 寸 480×320，320×240 居中，10–11fps，偶发彩色闪帧） |
| 加强③ | 编写手机 APP，通过网络远程实时监看摄像头视频 | ✅ PC 中继 + Web APP：192×144 @3.0fps，手机已实测（最终可用 ATK-ESP8266 替换 PC 中继） |

## 3. 交付物

1. **硬件接口电路**（原理图）。
2. **控制程序**：程序设计流程图 + 程序清单，代码附详细注释。
3. **设计报告**：Word 文档，含封面、任务书、正文、实物工作图（按学校模板）。
   - 正文约 **10–15 页**：引言、系统框图、硬件原理、软件设计（流程图）、成果分析、总结。
   - 附 1：实物工作图片 2–4 张。
   - 附 2：参考文献。
   - 附 3：组内分工。
4. **使用说明**（详细）。
5. **PPT**：10 分钟报告 + 实物演示 + 5 分钟问答。
6. **成绩评定表**：电子版 + 纸质版（填写成员分工及实现功能，不填成绩）。

## 5. 验收内容

1. 制作 PPT，准备 **10 分钟报告 + 实物演示 + 5 分钟问答**。
2. 课程设计报告（按 `课程设计文档模板.doc`）。
3. 系统仿真/调试过程及结果。
4. 演示实物；实物上贴标签纸，写“班级 + 组员姓名”。

## 6. 进度安排（4 周）

| 周次 | 任务 |
|---|---|
| 第 1 周 | 分组（最多 4 人），方案设计 |
| 第 2 周 | 方案设计 + 编程（周一/三/五 14:30–17:00 开放实验室） |
| 第 3 周 | 编写程序并调试 |
| 第 4 周 | 程序完善 + 写报告，第 4 周验收 |

> 当前是单人完成全部角色；如果按 4 周进度，需要把报告/PPT 与网络/APP 并行推进。

## 7. 元器件采购

- 控制板：STM32/S3C2440 实验板可向系里借，也可用自己的（不报销）。
- 其他元器件（**摄像头和显示屏除外**）以班为单位由学委统一采购；每组不超过 **80 元**；需收据、发票及支付证明。
- 网络模块（ATK-ESP8266 / ESP-01S / ESP32）属于“其他元器件”，需在预算内。

## 9. 已知问题

- LCD 偶发彩色闪帧（FIFO 读写竞争），当前用 VSYNC 下降沿 + 10ms 读前延时压到“偶尔还有”。
- 上电第一次 `ov7670_init` 偶尔返回 1（SCCB 复位 NACK），主循环重试后成功；可加初始化重试。
- 未使用 ALIENTEK OV7725 驱动，工程里仍保留 `ov7725.c`（USMART 引用），最终可清理。
