# HIL 检查单（宠物视频监控系统）

> 每项：输入 → 观测 → 结论（通过 / 需修 / 阻塞 / 未跑）。观测数据注明仪器、端口、波特率与来源；未跑不编造。
>
> 通用模板来自 `embedded-fw-starter`，本文件已按战舰V3 + OV7670/AL422 + LCD + ESP8266 + 安卓 APP 增补。

## 0. 环境基线

| 项 | 值 |
|---|---|
| 开发板 | 正点原子战舰V3，STM32F103ZET6，512KB Flash / 64KB RAM |
| 调试串口 | USART1，PA9/PA10，115200，板载 CH340 → COM22 |
| 烧录方式 | 当前：BOOT0=1 + ATK-XISP 串口 ISP；ST-Link 到位后：SWD |
| 编译 | Keil MDK 5.24a，ARMCC/AC5，STM32F1xx_DFP 2.2.0 |
| 串口工具 | XCOM / VOFA+ / Python(pyserial 3.5, Miniconda) |
