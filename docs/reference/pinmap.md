## 2. 模块侧：22 脚 OV7670 + AL422（用户丝印，已确认）

> 用户读出的丝印（两排，共 22 脚）：
>
> - 第一排：`3V3 SIOC VSY D7 D5 D3 D1 RST STR WR WRST`（11 个）
> - 第二排：`GND SIOD HREF D6 D4 D2 D0 PWDN RCK OE RRST`（11 个）
>
> 模块背面有**金属壳晶振**，XCLK 由模块自己提供，不需要 MCU 接时钟。

### 2.2 接线顺序（务必按此顺序）

1. **断电**，拔掉 USB_232。
2. 先接 `GND`（模块 GND ↔ P6 18）。
3. 再接 `3V3`（模块 3V3 ↔ P6 17）。
4. 接 SCCB：`SIOC → PD3(P6-2)`、`SIOD → PG13(P6-4)`。
5. 接 FIFO 控制：`WRST→PD6(P6-1)`、`WR→PB3(P6-16)`、`RRST→PG14(P6-3)`、`RCK→PB4(P6-14)`、`OE→PG15(P6-5)`、`VSY→PA8(P6-15)`。
6. 接数据线：`D0–D7 → PC0–PC7(P6-6..13)`，**按标签一一对应，不要按排针位置猜**。
7. `RST` 接 3.3V（最好串 10K，无电阻可直连）；`PWDN` 接 GND；`STR`、`HREF` 悬空。
8. 上电前用万用表测 3V3–GND 不短路；上电后测模块 3V3 对 GND 应为 3.2–3.4V。

## 3. 一般映射规则（确认丝印后按此接线）

| 模块信号 | 板上 P6 | 处理 |
|---|---|---|
| 3V3 / VCC | 17（3.3V） | 只接 3.3V，**禁止接 5V** |
| GND | 18 | 先接 GND，再接 3.3V |
| SCL / SIOC | 2（PD3） | SCCB 时钟 |
| SDA / SIOD | 4（PG13） | SCCB 数据 |
| VSYNC / VSY | 15（PA8） | 帧同步 |
| WRST | 1（PD6） | FIFO 写指针复位 |
| WEN / WR | 16（PB3） | FIFO 写使能 |
| RRST | 3（PG14） | FIFO 读指针复位 |
| RCLK / RCK | 14（PB4） | FIFO 读时钟 |
| OE | 5（PG15） | 若模块无 OE，可不接；模块内部可能已拉低 |
| D0–D7 | 6–13（PC0–PC7） | 8 位数据 |
| RST / RESET | 无 | 模块若有，接 3.3V（10K 上拉）或悬空（模块内部上拉） |
| PWDN | 无 | 模块若有，接 GND（正常工作） |
| XCLK | 无 | 若模块有板载 12MHz 晶振，可不接；否则必须由 MCU 提供时钟 |
| HREF / PCLK | 无 | FIFO 模式下模块内部使用，MCU 不需要 |

## 4. 上电前安全检查（必须逐项做）

- [ ] 断电状态下，万用表测模块 3V3 与 GND 之间电阻，**不能接近 0 Ω**（排除电源短路）。
- [ ] 确认模块电源丝印是 3.3V，不是 5V。
- [ ] 确认板上 P6 的 17 脚是 3.3V、18 脚是 GND（对照丝印/原理图）。
- [ ] 先接 GND，再接 3.3V，最后接信号线；断电时拆线顺序相反。
- [ ] 上电后用万用表测模块 3V3 对 GND 电压，应在 3.2–3.4V。
- [ ] 若模块发烫、冒烟或电流异常，立即断电。
