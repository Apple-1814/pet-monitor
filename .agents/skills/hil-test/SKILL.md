# hil-test

## 输入

- 当前任务的目标平台、约束与已有产出(从 `fw/`、`tooling/toolchains.json`、`HANDOFF.md` 读取,不凭记忆)。

## 步骤

1. 核对前置:目标平台与工具链版本以 `tooling/toolchains.json` 为准,不一致先报告再继续。
2. 执行本技能核心动作,产出文件落到约定目录(`fw/`、`drivers/`、`tests/`)。
3. 自验:宿主侧可跑的检查先跑(编译告警、静态检查、单测);需要硬件的项明确标注"未验证(需 HIL)"。
4. 记录:关键命令、产物哈希与结论写入 HANDOFF;不伪造未执行的验证。

## 输出

- 产出文件清单与自验结果;证据层级(单测/静态/HIL)逐项注明。
