# experiment-log

## 输入

- 当前任务目标与已有产出(从 `paper/`、`experiments/`、`literature/`、`compliance/`、`HANDOFF.md` 读取,不凭记忆)。

## 步骤

1. 核对前置:目标会议/期刊要求、已有章节与实验记录、合规声明状态。
2. 执行本技能核心动作,产出落到约定目录。
3. 自验:图表跑数据溯源核对、引用跑 bib↔正文一致性;不声称未执行的验证。
4. 记录:关键命令、编译日志与结论写入 HANDOFF;实验与图表结论必须可复现。

## 输出

- 产出文件清单与自验结果;涉及"已验证/已达成"的声明附证据。
